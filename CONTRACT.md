# Bao Assistant implementation contract
Private, single-owner Next.js 16.4.5 / React 19.3.1 / TypeScript App Router app for Vercel. Node22. Project root /home/nekoartisan/bao-assistant. No ERP. Backend owns lib/, app/api/, tests/backend/, db/, README, .env.example, vercel*.json. Frontend owns app/page.tsx app/layout.tsx app/globals.css components/ tests/ui/. Parent owns package.json tsconfig and integration.

API JSON:
GET /api/status -> {authenticated:boolean, configured:boolean, missing:string[], timezone:'Asia/Bangkok', accounts:[{email:string,lastSyncAt:string|null}], lastSyncAt:string|null, gaps:string[]}. No secrets. Non-auth status only reveals configured/authenticated and generic setup state, never email.
POST /api/auth/login {password} -> sets httpOnly session cookie or error; POST /api/auth/logout.
GET /api/dashboard?weeks=1 (1-8) -> {items: Deadline[], news: News[], gaps:string[], lastSyncAt:string|null}; all protected, no demo/fake data. Backend may use extra fields.
POST /api/sync -> bounded incremental sync mail/calendar/news; returns {ok:boolean, summary:string,gaps:string[]}; no Gmail mutations. Pagination cursors resume safely; full threads read, never mark snippets as full coverage. Initial lookback 90d, process at most 10 threads per request, durable cursor continues. No time-inventing.
POST /api/chat {message:string,weeks?:number} -> {answer:string,sources:[{title:string,url:string}],gaps?:string[]}; grounded in database. Prompt injection treated as data. Chat can answer weekly priorities + recent weeks news. No mutations via chat.
PATCH /api/items/<id> {status?:'open'|'done'|'dismissed',dueAt?:string|null,dateOnly?:string|null,title?:string} explicit UI review; validate dates, no external calendar mutation.
GET /api/google/connect -> OAuth redirect (protected). callback /api/google/callback supports both owner emails with gmail.readonly + calendar.readonly; refresh tokens AES-GCM encrypted, never expose/export local Hermes tokens.
GET /api/cron?task=morning|evening|poll -> bearer CRON_SECRET; durable dedupe/lease and reminders, telegram + optional RESEND email to owner. Default vercel.json 2 DAILY schedules 0 23 * * * (06 Bangkok), 0 14 * * * (21 Bangkok). Frequent poll example separate opt-in Pro/external scheduler. Honest Hobby timing caveat.

Deadline {id:string,title:string,kind:'deadline'|'exam'|'event'|'commitment',dueAt:string|null,dateOnly:string|null,timezone:string|null,originalDateText:string,evidence:string,sourceUrl:string,sourceAccount:string,status:'open'|'done'|'dismissed'|'needs_review',confidence:number,updatedAt:string,notes?:string,location?:string}. timezone null if ambiguous; dateOnly no fake midnight deadline. Exact quote evidence must be substring of full mail body. Changed dates reconciled/superseded not duplicated; cancellations not reminders. Structured LLM extraction validation via zod. Retain multi-date facts independently, not first date only. 
News {id:string,title:string,summary:string,url:string,publishedAt:string,source:string,kind:'paper'|'news',fetchedAt?:string}. arXiv API + official RSS fallback with separate publication/fetch times; persist and filter requested week windows; errors distinct from no items.

Security: no public inbox; single-owner password >=16, signed expiring cookies SameSite strict, mutation origin guard, DB rate limiting, OAuth signed state cookie+PKCE, allowlist two owner emails, encrypted refresh tokens, sanitized outgoing messages/HTML, no raw error secrets. Database durable Postgres via postgres driver (Neon compatible SSL DATABASE_URL). Need explicit migration command not in-memory storage. All integrations use server-only env; no secrets copied from host into project. Missing credentials -> explicit setup state, not fake output. Real tests first RED then implementation per slice; record test results. Report unavailable live integrations honestly.

Design surface: Monitor primary, Command/Inspect secondary. Warm off-white ink forest-green, readable dense agenda + assistant side panel, mobile layout. Header Bao / Personal desk, week range, sync state, filters for This week / Next weeks / Review / Research, dated agenda with source evidence, chat shortcuts, settings connect/login state; no hero or fake stats. Functional loading/error/empty/configuration states, all actions real fetches. Do not access backend secrets from client.
